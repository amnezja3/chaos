# Message SFX assets

Runtime expects these optional MP3 files:

- `01_incoming.mp3` — new foreign Cyberner message;
- `02_sent.mp3` — quiet confirmation of the player's own message;
- `03_warning.mp3` — system warning;
- `04_critical.mp3` — critical system message.

Missing assets fail silently through the shared GameSfx negative cache.
